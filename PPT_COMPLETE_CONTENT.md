# SLIDE 7: PROJECT OVERVIEW
## (Red Header: "Student Performance Prediction - Overview")

**Student Performance Prediction** is an AI-powered web application that predicts a student's final exam marks based on key academic and lifestyle factors.

The system allows users to input **study hours, attendance percentage, previous marks, and sleep hours** to receive an accurate prediction of their expected performance.

Built with the **Flask framework** and **scikit-learn**, the application provides a clean, responsive interface with real-time predictions powered by a trained **Gradient Boosting Regressor model** achieving **80.82% R² accuracy** (Test Set).

The platform focuses on helping students understand the factors affecting their performance and plan their study strategies with:
- **Grade Classification** (A+ to F)
- **Smart Target Planner**
- **Personalized Suggestions**
- **Performance Status**

It goes beyond simple prediction by providing actionable insights for academic improvement.

# SLIDE 16: MODEL TRAINING PROCESS

**4. Model Evaluation**
- R² Score: 80.82% (Test), 78.35% (Train)

- RMSE: 4.99 marks (Test)
- Low overfitting: 2.47% gap
