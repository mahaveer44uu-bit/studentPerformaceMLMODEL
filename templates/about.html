About the Model

This application estimates a student's final marks from four academic and lifestyle factors. It is designed as a learning and planning tool, not as a replacement for academic evaluation.

Try a Prediction

Algorithm

The project uses a Gradient Boosting Regressor model trained on 5000 student records with 80.82% accuracy. It predicts continuous scores between 0 and 100, making it suitable for numerical mark prediction.

Input Features

  • Daily study hours
  • Attendance percentage
  • Previous marks
  • Average sleep hours

Output

The system returns predicted marks, a grade, a performance status, and simple rule-based suggestions. The suggestions are generated from input conditions and the predicted result.

Responsible Use

Predictions are estimates based on the training data. Actual results can differ because many real-life factors are not included in this small academic project.
