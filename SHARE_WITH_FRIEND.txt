┌───────────────────────────────────────────────────────────────┐
│ STEP 1: FIND YOUR IP ADDRESS                                  │
└───────────────────────────────────────────────────────────────┘

Method A (Easiest):
→ Double-click: GET_IP_ADDRESS.bat
→ You'll see something like: 192.168.1.5

Method B (Command):
→ Open Command Prompt
→ Type: ipconfig
→ Look for: IPv4 Address . . . : 192.168.1.5


┌───────────────────────────────────────────────────────────────┐
│ STEP 2: MAKE SURE APP IS RUNNING                              │
└───────────────────────────────────────────────────────────────┘

→ Run: python app.py
→ Terminal should show: "Running on http://0.0.0.0:5000"
→ Test on YOUR browser: http://localhost:5000 ✓


┌───────────────────────────────────────────────────────────────┐
│ STEP 3: SHARE URL WITH FRIEND                                 │
└───────────────────────────────────────────────────────────────┘

If your IP is: 192.168.1.5
Tell friend to open: http://192.168.1.5:5000

Format: http://YOUR_IP_ADDRESS:5000

⚠️ Important:
✓ Use http:// (NOT https://)
✓ Use YOUR IP (NOT localhost)
✓ Include :5000 at the end


┌───────────────────────────────────────────────────────────────┐
│ STEP 4: BOTH MUST BE ON SAME NETWORK                          │
└───────────────────────────────────────────────────────────────┘

Option A: Same WiFi
✓ Both connect to same WiFi network
✓ Should work immediately

Option B: Mobile Hotspot
✓ Turn on hotspot on your phone
✓ Both connect to your hotspot
✓ Find NEW IP address (will change!)
✓ Share new URL


┌───────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                               │
└───────────────────────────────────────────────────────────────┘

Problem: Friend can't access
─────────────────────────────────────────────────────────────

Check 1: Same Network?
→ Are you both on same WiFi?
→ Test: Friend pings you: ping YOUR_IP
→ Should get replies

Check 2: Firewall?
→ Windows may block Python
→ When you run app, did alert appear?
→ Click "Allow access" if prompted

Check 3: Correct URL?
→ Friend using YOUR IP (not localhost)?
→ Using http:// not https://?
→ Port :5000 included?

Check 4: App Running?
→ Is terminal still showing app running?
→ Any errors in terminal?


┌───────────────────────────────────────────────────────────────┐
│ QUICK FIX: USE NGROK (If Same Network Doesn't Work)           │
└───────────────────────────────────────────────────────────────┘

Step 1: Download ngrok
→ Go to: https://ngrok.com/download
→ Download for Windows
→ Extract the file

Step 2: Run your app
→ python app.py

Step 3: Run ngrok (in new terminal)
→ ngrok http 5000

Step 4: Share the URL
→ You'll see: https://abc123.ngrok.io
→ Share this with friend
→ Works from ANYWHERE! (even different city!)

Advantage:
✓ No network issues
✓ Works remotely
✓ Looks professional
✓ HTTPS secure
