────────────────────────
• App sleeps after 15 min inactivity
• First request after sleep: 30-60 sec delay
• 750 hours/month free
• Perfect for demos/testing

💡 Before Demo:
──────────────
• Visit your app 5 minutes before demo
• Keep a tab open (prevents sleep)
• Have localhost backup ready

🔄 Update Your App:
──────────────────
• Make changes locally
• git add . && git commit -m "message" && git push
• Render auto-deploys (wait 5-10 min)

Problem: Git not found
Solution: Install from https://git-scm.com/download/win

Problem: GitHub auth failed
Solution: Use Personal Access Token (not password)
         GitHub → Settings → Developer → Tokens

Problem: Build failed on Render
Solution: Check requirements.txt format
         Check Render logs for error

Problem: Model not found
Solution: Ensure student_model.pkl is in repo
         Check it's not in .gitignore

Problem: Slow first load
Solution: Normal for free tier (app was sleeping)
         Visit 5 min before demo
